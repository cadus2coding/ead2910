# Página sobre a Faculdade Municipal de Palhoça (FMP)

Projeto desenvolvido para a disciplina de Programação Web do curso de ADS.

## Qual é a função do HTML na página?
O HTML organiza os elementos, como títulos, parágrafos, imagem, lista e botão.

## Onde você utilizou CSS e quais alterações ele realizou?
Usei CSS no arquivo `style.css` para mudar o fundo, as cores e os tamanhos dos textos, além de estilizar o botão, arredondar as bordas e organizar o conteúdo.

## Onde você utilizou JavaScript e o que acontece quando ele é executado?
Usei JavaScript no arquivo `script.js`. Quando clico no botão, uma das mensagens sobre os estudos aparece na página, escolhida aleatoriamente.

## Qual é a principal diferença entre CSS e JavaScript?
CSS controla a aparência da página, enquanto JavaScript permite criar ações e interações.

## Como executar
Abra `index.html` no navegador com conexão à internet para carregar a imagem ilustrativa.

**Observação:** este é um trabalho acadêmico demonstrativo, não um site oficial da FMP. Revise e adapte as respostas com suas próprias palavras antes de entregar.
